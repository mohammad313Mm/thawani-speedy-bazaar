# إضافة «العامة» كخيار تسجيل داخل التصنيف

## الوضع الحالي (بعد الفحص)
- صفحة إكمال معلومات المتجر تحتوي قسم «التصنيف» مع أزرار (مطاعم، كوزمتك، بقالة…)، وتطلب: صورة غلاف + شعار + اسم + هاتف + وصف + تصنيف + تحديد الموقع.
- تحديد الموقع يتم عبر المكوّن الحالي «تحديد موقعي» الذي يحفظ الإحداثيات على المتجر، ثم يعيد الخادم استخراج المنطقة تلقائيًا.
- التسجيل أصلاً خاضع لموافقة الإدارة (الدخول للوحة المتجر لا يتم إلا بعد الموافقة).
- «العامة» موجودة بالفعل كمتاجر مميّزة بعلامة خاصة، وتظهر للزبون ضمن منطقته فقط، وصفحة الطلب الحر جاهزة وتستخدم نفس نظام الطلبات والمناطق وأجور التوصيل.

## ما سيتم تنفيذه

### 1) خيار «العامة» في قسم التصنيف
- إضافة زر «العامة» بجانب بقية التصنيفات في صفحة إكمال معلومات المتجر.
- عند اختياره تُخفى تلقائيًا: صورة الغلاف، الشعار، وصف المتجر، وبقية حقول المتجر العادي.
- يبقى ظاهرًا فقط: رقم الهاتف + قسم تحديد موقع المتجر (نفس الزر والآلية الحالية).
- زر الحفظ يصبح «إكمال التسجيل»، ويشترط فقط رقم الهاتف والموقع.
- عند الحفظ يُعلَّم المتجر كمتجر «عامة» ويُفتح لاستقبال الطلبات، ويُربط تلقائيًا بالمنطقة المستخرجة من موقعه حتى يظهر للزبائن في تلك المنطقة فقط.
- لا تغيير على مسار التصنيفات العادية إطلاقًا.

### 2) واجهة صاحب متجر «العامة»
- بعد الدخول تظهر نفس لوحة المتجر الحالية لكن بدون تبويب «المنتجات» (لا معنى له للعامة).
- تبقى: الطلبات، تفاصيل الطلب، قبول/رفض الطلب، وحالة المتجر متوفر/غير متوفر، وقسم تحديد الموقع — كلها من النظام الحالي دون تكرار.

### 3) مسار الزبون: أيقونة «العامة» ← قائمة المتاجر
- إضافة صفحة جديدة `/general` تعرض متاجر «العامة» المفعّلة في منطقة الزبون فقط، مع شارة «غير متوفر» للمغلق.
- في الصفحة الرئيسية تُعرض «العامة» كأيقونة واحدة تنقل إلى تلك القائمة (بدل عرض المتاجر مباشرة)، ثم اختيار المتجر يفتح صفحة الطلب الحالية كما هي.
- المتاجر المعطّلة أو المحذوفة أو خارج المنطقة لا تظهر.

## تفاصيل تقنية
- تعديل `StoreSetup` في `src/routes/merchant.dashboard.tsx`: خيار تصنيف افتراضي `__general__` يضبط `is_general = true` مع `category = null`، وإخفاء الحقول غير المطلوبة، وحفظ `phone/latitude/longitude/is_open` ثم استدعاء `syncMyStoreArea` الحالي.
- دالة خادم جديدة صغيرة في `src/lib/general.functions.ts` (بصلاحية المالك) لربط المتجر بمنطقته في `general_store_areas` بعد حفظ الموقع.
- إخفاء تبويب المنتجات عندما `is_general` في لوحة المتجر.
- صفحة `src/routes/general.index.tsx` تستخدم `listGeneralStores` الحالية مع منطقة الزبون.
- لا تعديل على الطلبات، المندوبين، الإشعارات، أجور التوصيل، المناطق، أو صلاحيات الإدارة.
